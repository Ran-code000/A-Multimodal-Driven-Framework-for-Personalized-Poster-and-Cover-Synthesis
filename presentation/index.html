// problem-statement

纯文本驱动的海报生成
面临四大核心挑战

01 · 构图不可控

纯文本生成的空间布局高度随机，无法满足海报版面结构的精确需求——主题位置、文字区域、视觉层次全凭"运气"。

❌ 随机布局

02 · 风格不可控

色彩调性、纹理肌理等视觉风格要素难以通过自然语言精确描述——"暖色调"可能有100种解释，生成结果与预期偏差大。

🎨 语义歧义

03 · 细节崩坏

人物面部、手部等高频细节区域易出现扭曲变形——这是潜在扩散模型在低维表示中高频信息损失的直接后果，严重影响商业可用性。

🧩 高频损失

04 · 多模态融合困难

文本（语义）、布局（空间）、风格（视觉）三种异构模态如何在潜在空间有效融合，是多模态可控生成的核心难题。

🔗 异构融合
海报生成面临的四大挑战：构图不可控——纯文本生成的空间布局完全随机。风格不可控——色彩和纹理难以用文字精确描述。细节崩坏——人脸和手部容易变形。多模态融合困难——文本、布局、风格三种异构信息如何在潜在空间有效融合。这四项挑战直接驱动了本系统的设计。

五大核心模块构成模块化流水线，三模态输入经独立预处理后在SDXL UNet内部实现互不冲突的潜在空间融合。

系统的核心架构：五个模块组成流水线。LLM提示词增强将简短中文主题扩展为高质量英文SDXL提示词。Canny边缘检测提取布局结构。ControlNet以弱约束方式注入布局条件，IP-Adapter以解耦交叉注意力注入风格特征。三者在SDXL UNet内部的不同网络层和注意力机制上独立作用、互不冲突——这是整个系统设计的核心原则。

control-strategy · weak-constraint

弱约束控制：在引导与自由之间

ControlNet-Canny · 弱约束策略

条件权重 0.15--0.55，远低于默认值 1.0。

低权重优势：避免"填色画"式的过度约束，保留SDXL的艺术创造力与多样性
构图引导：主体居中、三分法构图、横幅区域——仅引导趋势而非像素级定位
控制窗口：control_guidance_start=0.0, end=0.9——早期扩散步无约束，后期注入结构

IP-Adapter · 零样本风格迁移

通过 CLIP ViT-H 提取风格嵌入，仅引入约 3% 参数。

control-flow.py
# ControlNet: 像素/空间层面的结构约束
if layout_image:
    control_image = canny_preprocess(layout_image)
    result = pipe(image=control_image,
                  controlnet_conditioning_scale=0.55)

# IP-Adapter: 语义/风格层面的外观调制
if style_image:
    pipe.load_ip_adapter("h94/IP-Adapter")
    pipe.set_ip_adapter_scale(0.40)

# 两者控制维度天然正交 → 联合使用且效果互补
控制策略的核心创新是弱约束。ControlNet权重只有0.15到0.55，远低于默认的1.0——这样避免了填色画式的僵化效果，保留模型的创造力。IP-Adapter仅增加3%的参数，通过CLIP视觉编码器实现零样本风格迁移。两者分别作用于像素空间和语义空间，相互独立、协同增效。

关键发现

🔬 正交性验证

G4增益（12.2%）≈ G2增益（4.6%）+ G3增益（7.9%）= 12.5%。
布局与风格控制维度互不干扰，协同增效。

📊 FID ≠ 质量

G4的FID最高（3.47）说明分布重塑程度最大——但这是正向重塑（G4在所有指标上均为最优）。高FID ≠ 质量差。

🎯 主题敏感性

赛博朋克提升最小（+11.0%），青绿山水提升最大（+14.9%）——抽象传统画风对多模态控制最敏感。

定量结果的核心亮点：G4 CLIP Score提升12.2%，美学指标提升24.7%，主观评分提升51.9%。最关键的科学发现是正交性验证——G4增益接近G2与G3增益的线性叠加，说明布局控制与风格控制在语义空间中互不干扰、协同增效。
